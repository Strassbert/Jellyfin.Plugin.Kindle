Mail server (SMTP)

These credentials are used to send books for every user on this server.

Fills in host, port and encryption. Username and password still have to be entered.
For example smtp.gmail.com
Port 465 needs "SSL/TLS on connect". The previous versions could only do STARTTLS, which is why port 465 never worked.
Leave empty for a relay that needs no login.
Gmail, Outlook and most providers reject your normal account password here. Create an app password instead.
Leave empty to use the username. This address must be approved in the reader account, otherwise every mail bounces.

Delivery

Sends "convert" as the subject line. Only relevant for Amazon Kindle; leave off for other readers.
Provider limit for the whole email. Amazon allows 50 MB.

Users

Every user sets their own reader address under Settings > E-Book Share. Nobody can see or change another user's address.
