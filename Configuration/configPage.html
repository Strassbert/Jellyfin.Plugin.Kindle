Mail server (SMTP)

These credentials are used to send books for every user on this server.

Fills in host, port and encryption. Username and password still have to be entered.
For example smtp.gmail.com
Port 465 needs "SSL/TLS on connect".
Leave empty for a relay that needs no login.
Gmail, Outlook and most providers reject your normal account password here. Create an app password instead.
Leave empty to use the username. This address must be approved in the reader account.

Test message

A connection test only proves that login works. It cannot detect that the reader vendor rejects your sender address - send a real test message to check that.

Delivery

Sends "convert" as the subject line.
Provider limit for the whole email. Amazon allows 50 MB.
